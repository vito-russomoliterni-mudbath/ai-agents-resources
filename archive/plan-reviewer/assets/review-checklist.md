# Plan Review Checklist

Use this checklist to ensure a thorough review of the proposed plan.

## Command Accuracy
- [ ] Are all shell commands syntactically correct?
- [ ] Have you verified the flags and parameters against current documentation?
- [ ] Are tool versions (e.g., node, python, git) compatible with the environment?
- [ ] Are file paths correct and accessible?

## Best Practices
- [ ] Does the plan follow the project's established coding style?
- [ ] Are you using the most idiomatic solution for the problem?
- [ ] Have you checked for security implications (e.g., hardcoded secrets, unsafe shell inputs)?
- [ ] Does the plan include necessary testing and validation steps?

## Codebase Compatibility
- [ ] Have you checked for existing functions or modules that perform similar tasks?
- [ ] Are there potential side effects on other parts of the system?
- [ ] Does the plan respect the project's architectural boundaries?
- [ ] Are dependencies correctly handled?

## Doubt & Ambiguity
- [ ] Is there any part of the plan you are "guessing" on?
- [ ] Have you exhausted codebase exploration for unclear areas?
- [ ] If significant uncertainty remains, have you flagged it for the user?
